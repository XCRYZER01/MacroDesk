# Background image sources

The `ui_*_clean_800x480.png` files deliberately contain no interactive button
labels, shortcuts or icons; those belong to the runtime UI. Run
`tools/New-CleanBackgrounds.ps1` to rebuild the final 800 x 480 files.

## PrusaSlicer

- Source: [Original Prusa MK4 media assets](https://www.prusa3d.com/page/media-assets_987/)
- Files used: official MK4 preview photograph and
  `MK4_product_photo_transparent.png` from `OriginalPrusaMK4.zip`
- Local files: `source_photos/prusa_mk4_official.jpg` and
  `source_photos/prusa_mk4_product_official_512.png` (resized to 512 x 512)
- Note: Original Prusa and PrusaSlicer names and marks belong to Prusa Research.

## OrcaSlicer

- Source: the project's existing `ui_orca_800x480.png` artwork.
- Clean edit master: `source_photos/orca_original_clean_master.png`
- Changes: removed only the baked-in interactive icons, labels and shortcuts;
  retained the original Orca header art, frame, palette and button geometry.

## Fusion 360

- Source: the project's existing `ui_reference_800x480.png` artwork.
- Clean edit master: `source_photos/fusion_original_clean_master.png`
- Changes: removed only the baked-in interactive icons, labels and shortcuts;
  retained the original Fusion header art, frame, palette and 5 x 4 grid.
- Note: Autodesk Fusion 360 is a trademark of Autodesk, Inc.

## Onshape
